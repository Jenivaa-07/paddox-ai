# Documented Historical Data Information

Version: 1.0.0
Date: 2026-07-30

## Data Availability
The PADDOX platform provides historical race data, qualifying times, and telemetry spanning back to the 2014 hybrid era. Data before 2014 is currently not supported for programmatic access but may be viewed through the archival dashboard.

## Data Granularity
For seasons 2018-present, telemetry data is available at 10Hz, including throttle, brake, speed, and gear parameters.

## API Limits
Accessing historical data via the PADDOX API is limited to 100 requests per minute for standard accounts and 500 requests per minute for VIP users.
